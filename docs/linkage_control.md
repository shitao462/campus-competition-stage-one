# 姿态联动实现与 PID

## 数据与状态

- A/B 为 GM6020 ID 1/2，CAN1 反馈 ID 为 0x205/0x206，分别进入 FIFO0/FIFO1。
- 编码器 0–8191 转换为 rad 并跨圈展开，速度 rpm 转换为 rad/s。方向和电流指令使用同一个方向系数。
- BMI088 静止采集 200 个样本估计三个陀螺仪轴的零偏。运动超过校准阈值时重新计数。
- 复用中间件 Mahony 计算姿态，展开 yaw 的 ±π 跳变。未引入磁力计，因此 yaw 为相对角度，长期仍有漂移。
- 使用实际经过时间补偿 Mahony 的固定 10 ms 步长；超过 50 ms 的间隔不补积分，该轮禁止联动。
- yaw 的欧拉角在竖直姿态附近不可靠；俯仰超过约 69° 时禁止联动，验收时将板子近水平绕 yaw 转动。
- 只有右拨杆中档、IMU 就绪且新鲜、两个电机在线、温度低于 80°C 时使能。
- 下档、遥控器断联、任一电机断联、IMU 无效时发送零电流并清除控制器状态。上档执行固定角度映射的试验复位。

## 共同参考点

进入中档时记录板子角度 ψ₀、A/B 当前角度 a₀/b₀。定义虚拟输入 q 和偏移 o：

```text
q = yaw - ψ₀ + o
target_a = a₀ + q
target_b = b₀ + r × q
```

左拨杆下/中/上分别选择 r = 0.5/-1/3。A 的比例始终为 1。切换比例时捕获当前位置作为新的起点，保持目标连续。
角度连续展开，因此 1:3 可跟随多圈，不将每次位置误差压缩为最短的 ±π 路径。

当 C 板近乎静止，电机偏离目标超过 0.025 rad、速度超过 0.08 rad/s，且连续 40 ms 向远离目标的方向移动时，将其判定为手动输入。
正常跟随运动朝向目标，不满足这个判据。源电机电流清零，另一台仍由 PID 跟随。

```text
手动 A：q = angle_a - a₀
手动 B：q = (angle_b - b₀) / r
o = q - (yaw - ψ₀)
```

这里只改变虚拟参考，绝不改写实际测量 yaw。虚拟参考 yaw 为 ψ₀ - o，独立于复位方向映射。
源电机停止超过 300 ms，且从动电机误差小于 0.008 rad、实际速度小于 0.05 rad/s、电流小于 0.01 A、滤波目标速度小于 0.01 rad/s 连续 200 ms 后，才正常退出手动状态；另外，从动电机停稳 150 ms 后的新手动动作可提前接管，即使还有位置残差。在从动电机追赶和过冲阶段，原源电机保持零电流，防止从动电机的伺服运动反过来改写联动参考。松手超过 300 ms 后转动 C 板超过 0.005 rad，可恢复板子联动，同时继续保护未停稳的从动电机不被识别为手动源；保留 o，不返回旧零点。
没有外部力矩传感器，手动输入是基于运动方向的推断。识别前会有短暂的 PID 抵抗，极慢转动、跟随过冲或同时操作两台电机可能影响识别，需要实物调整阈值。
本次按题目顺序测试单个输入；不保证同时旋转板子和手动源电机的输入叠加。

## PID 如何使用

控制周期 5 ms，复用 sp::PID，未修改任何中间件源码。

```text
目标角度 → 位置 P 环 → 目标速度 → 速度 PI 环 → 电流给定 → 电机
              ↑ 实际角度                ↑ 实际速度
```

位置环：目标速度 = Kp_position × (目标角度 - 实际角度) + 滤波后的目标角速度，限制在 ±1.0 rad/s。
目标角速度从最终目标角度的变化计算，采用时间常数 40 ms 的低通滤波，因此板子输入和手动输入均可使用前馈。前馈帮助电机在小误差时继续运动，位置 P 负责纠正跟随误差，速度 PI 负责调整电流。
进入联动及手动源释放后的首次计算不对目标做差分，避免初始角度引起速度冲击；目标角速度原始值限幅 ±6 rad/s，最终速度和加速度限制仍生效。
速度环：电流 = Kp_speed × 速度误差 + Ki_speed × 速度误差积分，限制在 ±0.25 A。

初始参数：位置 Kp=2.5 s⁻¹，速度 Kp=0.13 A/(rad/s)，Ki=0.2 A/rad；速度积分项限制 ±0.05 A。
速度 P 项输出超过 0.20 A（电流上限的 80%）时暂停积分，减少大误差时的积分累积。
目标速度的加速度限制为 1.8 rad/s²，电流变化率限制为 0.8 A/s，减少启动和反转时的力矩冲击。
输出电流处于渐变限制或饱和状态时，下一控制周期暂停积分；速度反馈使用约 20 ms 的一阶低通滤波，降低 rpm 量化跳动。
仅当位置误差小于 0.008 rad（约 0.46°）、实际速度小于 0.05 rad/s、滤波后的目标速度小于 0.01 rad/s，且目标角度近乎不变，连续满足 100 ms 后，才清除速度积分并渐变释放残余电流。目标继续变化时不因误差小而反复归零，减少低速跟随的停走；这仍会容许静止时该范围内的位置误差。
失能和手动源电机释放直接清零，优先于普通运行时的电流渐变限制。
位置环 I、D 和速度环 D 初始设为 0。位置积分会加重手动操作时的抵抗；速度反馈已经提供阻尼，暂不增加放大测量噪声的微分项。
禁用、切换比例、进入/退出手动模式时清除 PID 状态，避免旧积分产生突然输出。
电流按手册 ±16384 对应 ±3 A 编码，以 0x1FE 给 ID 1/2 发送指令；0x2FE 的其他电机输出保持零。

这组参数用于首次低速验证，并非已调好的最终参数。建议先确认方向和比例，再小幅增加速度 Kp；抖动时降低 Kp。
只有存在稳定静差时才逐步增加 Ki；提高限流前应先确认机构固定、反馈正常且控制稳定。

## 串口观察

保留原有 IMU 和失能状态输出，每秒增加：

```text
imu_ready=1 ratio_b=3.0 yaw_rel_deg=0.00 enc=0,0 error_deg=0.00,0.00 current_A=0.000,0.000 manual=0 reset=1 done=1
```

上述角度字段单位为度，控制器内部仍为 rad，电流单位 A。manual=0 表示没有手动源，1/2 表示 A/B 手动输入。enc 为原始 0–8191 机械角度计数；reset=1 表示上档请求，done=1 表示两台达到配置目标，并不能验证印刷 R 标本身。
motor_disabled=0 才表示中档联动使能；若为 1，检查 rc_alive、两个 motor_alive、imu_ready 和温度。
target 为 0 不代表原始编码器的绝对零位；禁用时目标字段清零，仅启用后具有控制意义。

### SerialPlot：IMU 三轴角度

USART1 保留原有 `acc_mps2`、`gyro_radps` 和电机状态文字输出，同时在 IMU 就绪后每 100 ms 增加一行三通道 ASCII 数据（初始化或测量失效时暂停该行）：

```text
IMU:1.250,-2.500,62.145
```

通道顺序为 X/Roll、Y/Pitch、Z/Yaw，单位均为度。其中 Roll/Pitch 是姿态解算角，Yaw 使用与 `yaw_rel_deg` 相同的相对启动参考，不是全球绝对航向。原始三轴加速度和角速度仍在原文字输出中；绘图行只包含三轴角度。

SerialPlot 设置：

- Port：COM5（以实际连接为准），115200 波特率，8 数据位，无校验，1 停止位，无流控。
- Data Format：ASCII；Number Of Channels：3；Column Delimiter：comma。
- Filter by Prefix：Include；前缀准确填写 `IMU:`。Include 会去掉该前缀后解析三个逗号分隔数值，忽略其他文字行；见 [SerialPlot ASCII 解析实现](https://github.com/hyOzd/serialplot/blob/master/src/asciireader.cpp)。
- Plot 中三通道依次命名为 `Roll/X (deg)`、`Pitch/Y (deg)`、`Yaw/Z (deg)`。
- XCOM 与 SerialPlot 轮流打开 COM5，先关闭另一软件的端口；原有文字可以在 XCOM 或 SerialPlot 的 Text View 中查看。

绘图输出沿用现有 100 ms 打印周期，没有改变姿态解算、复位映射或 PID 参数。UART 仍使用现有阻塞发送路径，新增短行会增加少量发送时间；尚未进行本次硬件时序和实机绘图验证。

## 烧录验收顺序

1. 固定两台电机定子；确认 ID 为 1/2，均为电流模式。右拨杆下档，上电后板子保持静止。
2. 等待 imu_ready=1 且两个电机在线，切右拨杆中档。从板子上方观察逆时针缓慢转 60°；从电机输出轴端观察正方向。
3. 分别测试左拨杆三个档位：A 60°，B 30°、-60°、180°。通过角度增量而非绝对值比较。
4. 板子保持不动，手动转 A，再转 B；观察 manual 和另一个电机是否按比例跟随。
5. 松手后等待 manual 回到 0，确认不回旧零点；再转板子，确认从当前位置继续联动。
6. 切换左拨杆比例，确认目标不突跳；右拨杆下档或关闭遥控器，确认两台零输出。

编码器方向不符合实物安装时，只调整 motor_task.cpp 的 MOTOR_A_DIRECTION/MOTOR_B_DIRECTION，反馈和输出会一起变号。
如果板子与电机正方向定义不一致，先统一观察方向再修改系数，不要单独反转电流导致正反馈。

## 进阶第 3 项：固定映射复位

### bug1：1:3 档位的目标角度积压

用户反馈手动转 A 后 B 同方向继续追转一段时间。原两台电机均受 1 rad/s 目标速度和 1.8 rad/s² 加速度限制，而 B 需要完成 A 的三倍角度，因此容易积压目标。中档 1:3 时将 B 的速度和加速度限制分别提高至 3 rad/s、5.4 rad/s²，包含位置误差追赶与目标速度前馈。其他档位、复位模式、手动判定和固定映射保持原参数；总电流仍为 ±0.30 A，电流变化率仍为 0.8 A/s。

回归测试在三倍目标运动、B 已以 2.4 rad/s 跟随且有小幅落后时，检查控制输出不会受旧 1 rad/s 限制持续制动，并检查电流限幅、缓升和停止后目标保留。旧代码在该场景失败，调整后通过。真实负载下可达到的速度受 0.30 A 限制，快速手动输入仍可能积压目标；本调整尚待烧录实测，不保证任意输入速度下完全无追转。

在 IMU 首次就绪时只记录 C 板初始 yaw。电机使用独立的固定原始编码器映射，不记录电机启动位置作为零位。设 z_a/z_b 为 R 标对齐 C 板启动方向时的机械计数，s_a/s_b 为已有编码器/电流方向系数：

```text
board_delta = yaw - board_initial_yaw
direction_a = board_delta + s_a * z_a * 2π / 8192
direction_b = board_delta + s_b * z_b * 2π / 8192
```

上档每个控制周期各自取 direction 与当前角度的最短差 (-π,π]，按物理方向复位，不保留中档的整圈位置历史。目标速度前馈也按圆周差计算，避免等价目标跨整圈时产生突变。忽略左档比例、关闭上档手动识别，沿用平滑位置 P/速度 PI 和 0.25 A 电流限制。两台误差均小于 0.015 rad、速度小于 0.05 rad/s 且板子近静止连续 200 ms，标记 done=1；切中档重新捕获联动起点。正常切上档允许任意当前 yaw，无需先回到 0°。

“第六版”已保存到 GitHub 后，用户重新将 C 板与两台电机 R 标调为同向，并提供下档数据：motor_disabled=1、imu_ready=1、current_A=0.000,0.000，原始编码器 A=3310、B=3455；当时旧程序的 yaw_rel_deg=-17.69°。本次明确将这处同向的物理姿态选为新启动参考，配置 `applications/reset_mapping.hpp` 的 A=3310、B=3455。新固件在此姿态启动后会重新记录板子的初始 Yaw，因此直接采用这两个原始编码器读数。失能状态下的 `error_deg` 不用于映射计算。

本次标定后的首次烧录：保持右拨杆下档、当前 C 板方向与两个底座朝向固定，直接加载新固件，并保持静止直到 imu_ready=1；新程序 yaw_rel_deg 应接近 0°。此加载过程采用新启动方向，应保持当前对齐姿态，无需将板子转回旧程序的 yaw=0°。以后烧录或重新上电时，保持 C 板使用这次确定的物理启动方向、底座安装朝向固定；正常运行中切上档可以在任意当前 Yaw 复位。

映射只适用于本次测量的定子安装朝向和新 C 板启动方向。电机转子可以停在其他编码器位置，程序未将其启动位置记为零位；以后启动时不要求电机转子 R 标也对齐，但 C 板须保持已标定的启动朝向。底座仅平移不改变映射，底座转动会使其失效。仅把三者 R 标对齐后在不同物理方向重新启动，不能保证既有映射有效。PID、角度正负关系、中档接管修复、IMU 绘图和 0.25 A 上限保持“第六版”的实现。构建和软件回归只能验证计算与控制逻辑，真实 R 标的对齐效果需烧录确认。

复位模式 A 采用速度 Ki=0.4，B 采用 Ki=0.2，两台积分上限均为 ±0.15 A，解决原 ±0.05 A 积分限制下的静止残差；中档仍为 Ki=0.2、积分上限 ±0.05 A。两种模式总电流上限仍为 ±0.25 A，到位后清除积分并缓降电流。复位模式的积分释放保留误差、实测速度、滤波目标速度和持续时间条件，取消对单次微小目标变化的限制，避免 IMU 抖动阻止到位释放。

若保留已有物理启动方向，在 yaw_delta 非零时取得同向的编码器读数 e，则可计算映射计数 z = wrap_8192(e - s * yaw_delta * 8192 / 2π)。若将取得 e 的同向姿态明确设为新的物理启动方向，并在此姿态加载和初始化，则 z 直接取 e（本次采用此方法）。重启后 C 板需使用相同启动摆放方向；移动定子需更新映射。IMU 长期 yaw 漂移仍会影响方向精度。

模拟测试验证非零映射、正负方向系数、任意电机启动角度与多圈最短路径、上档不识别手动、不受左档比例影响、转板目标变化、到位与模式切换、编码器展开重置后仍按固定机械方向复位。它不验证配置的 R 标映射假设或真实电机动态。

### B 复位到位后的往返调整

B 复位速度积分增益从 0.4 降为 0.2，跨过目标时清除旧速度积分。误差小于 0.008 rad（约 0.46°）且速度和目标变化满足静止条件持续 100 ms 后，锁存到位释放状态；误差达到 0.015 rad（约 0.86°）、电机重新运动或目标速度增大时退出锁存并恢复纠偏。该逻辑只用于 B 的上档复位，A 和中档算法保持原参数。测试覆盖到位微扰不重新驱动、实际偏移恢复纠偏以及越过目标后的制动方向；实际往返振荡是否消除仍需烧录测试。

### 中档手动输入后的从动电机过冲与反向带动

用户反馈主要在 1:1 和 1:3、手动转 A 时发生；日志出现 manual=1 时 B 误差 -76.23°，之后 manual=0 且 A 误差约 43°。每秒日志不能完整重建中间输入源切换。代码可复现旧实现仅根据源电机静止 300 ms 就释放手动源，此时从动电机过冲会满足 moving_away 判据并被误认为手动输入。新增从动电机稳定后再释放的保护，主动源在等待期间保持零电流，允许原主动源继续转动并更新参考。转板恢复后也暂时屏蔽未停稳从动电机的手动判定。受保护的从动电机跨过目标时清除旧速度积分和速度参考，保留原电流渐变限制，以减小原方向继续驱动。

新回归覆盖三种比例、A/B 两种手动源、从动电机过冲不接管参考、不驱动原源电机、稳定后另一台可成为手动源、追赶时恢复板子联动、跨过目标后的电流方向及失能清零。过冲接管测试旧实现失败，修改后通过；不等同于真实电机动态已验证，仍需烧录测试。PID 增益、复位模式和 A/B 映射保持原参数，限流为 ±0.25 A。连续追赶及过冲阶段屏蔽从动电机接管；源电机停止 300 ms 后，从动电机实际速度低于 0.05 rad/s、滤波目标速度低于 0.01 rad/s 持续 150 ms，可重新接受其向远离目标方向的手动动作。不要求残余位置误差或保持电流清零。若从动电机先重新向目标运动，则取消这次接管机会，其后连续过冲仍受保护。手动动作仍通过运动方向推断，不能在相同的连续运动轨迹中可靠区分人为转动和伺服惯性。

### B 在中档 1:3 接近目标时提前减速

用户反馈 B 接近目标仍过快、先大幅超出再返回。只对中档 1:3 的 B 加入相对目标的接近速度约束：closing_limit = sqrt(2 × 0.8 × abs(position_error))，单位 rad/s。加速后的速度参考相对滤波目标速度也限制在此范围，避免原加速度斜坡保留过高的接近速度；目标速度前馈继续保留，以支持持续 1:3 运动。实际相对接近速度超出该界限且仍朝目标运动时清除旧速度积分，避免积分抵消制动。0.8 rad/s² 是保守的速度参考调参值，不是测得的真实减速度，也不能保证实际停距。

新增测试在远距离追赶后，模拟距目标 0.02 rad、实测速度 1 rad/s 的接近过程，检查在越过目标前及时输出制动电流，仍满足 0.25 A 限流和原电流变化率。该场景修改前失败、修改后通过；持续运动目标的三倍速度跟随回归仍通过。A、其他比例、复位模式和固定映射不启用此接近速度约束。真实惯量、摩擦与低电流下的制动效果仍需烧录实测。

### 修复 B 手动接管被过度保护阻止

用户反馈不能再手动转 B 带动 A。回归复现了从动电机已静止、残差 0.04 rad 时保护不解除的问题。增加停稳后重新接受手动输入的阶段：原源已停止 300 ms，受保护从动电机静止及目标速度低持续 150 ms，允许其新一次 moving_away 动作连续 40 ms 接管。接管时清除 PID、将新源电流置零并按原比例更新另一台目标。运动继续朝目标时撤销这次接管资格，避免后续过冲借用此前的静止状态。新增测试覆盖三种比例的 A→B 与 B→A 接管、残差和保持电流存在时新源零电流、以及停稳后伺服追赶再过冲不会接管。修改前接管测试失败，修改后通过；需烧录验证实际手动识别，B 的 1:3 接近速度限制保留。

### 中档 1:3 的 B 适度降速

按用户反馈，将 B 中档 1:3 的运动限幅系数从 3.0 调为 2.4：目标速度上限由 3.0 降为 2.4 rad/s（约 172°/s → 138°/s），目标加速度上限由 5.4 降为 4.32 rad/s²，均降低 20%。角度比例仍为 1:3，接近速度约束及停稳后的手动接管保留；A、其他比例和复位模式沿用原运动限制。连续跟随测试改用 A 0.7 rad/s、B 2.1 rad/s，检查在新速度上限内仍保持跟随驱动。全部控制器回归及编译通过，实际快慢需要烧录确认。快速输入时可能增加追赶时间，但目标角度不截断，最终角度比例不变。

### 停稳后交替手动转 A/B 的阻力

用户确认：在中档 1:3，两台停稳后，先转 A 再转 B 或先转 B 再转 A 都有较大阻力。旧判据要求离开目标超过 0.025 rad（约 1.43°）、速度超过 0.08 rad/s 并持续 40 ms；确认期间仍按旧目标输出位置和速度纠偏电流。新增软件场景模拟停稳后以 0.12 rad/s 交替转动，每次总位移仅 0.012 rad（约 0.69°），旧代码在场景 69 失败：新动作不能及时释放电流或成为手动源。此软件复现不等同于实测手部阻力。

修改后的低门槛只用于有停稳资格的新动作：无手动源的电机在原有到位条件下静止 100 ms 后锁存资格；受保护从动电机仍需原源停下 300 ms、自身及滤波目标速度低持续 150 ms 才允许新动作。该阶段的位置门槛为 0.006 rad（约 0.34°），速度门槛为 0.06 rad/s（约 3.44°/s）。运动方向仍须远离目标；近目标的停稳新动作可以沿任一方向识别。目标继续运动、板子明显转动或电机重新向到位范围外的目标追赶时取消资格，连续追转与过冲不借用之前的静止状态。

候选动作出现后，在 40 ms 确认期间就将候选电机指令电流置零并清除其速度 PID/环状态，原联动参考在确认前保持不变；确认后按 A 或 B 的实际位置更新虚拟参考，仍保持角度比例。若短动作停止、板子接管或保护不再允许接管，则清除候选计时；纠偏从零电流按原斜率恢复。手动源和候选源的零电流释放允许立即发生，其他正常伺服输出继续遵守原电流变化率与 ±0.25 A 上限。未修改复位映射、复位 PID、IMU 绘图或 B 的 1:3 降速参数。

新增回归覆盖三个比例、A→B/B→A、连续四轮正反方向慢转换手、资格确认期间零电流、保持残差时的新动作让步、短动作取消及零电流起步恢复；原连续从动过冲保护仍通过。新判据只能依据编码器运动推断手动动作，不保证在仍追转的相同轨迹中区分人手和伺服运动。修改后的真实手感和阻力需要烧录确认。
